# Presenter almahya (karakter orisinal)
`presenter(pose, t, talk)` -> string SVG (viewBox 0 0 600 700). Pose: idle, wave, point, warning, thumbs, explain.
`t` = detik (napas, kedip, gerak tangan wave); `talk=true` menggerakkan mulut. Dipakai di scene HTML Reels
(kartu presenter di sudut, pose mengikuti makna kalimat: sapaan=wave, info=point, peringatan=warning, ajakan=thumbs, penjelasan=explain).
Karakter ini buatan Claude, bisa diganti dengan karakter milik pemilik (PNG pose transparan) kapan saja.
